# FSD — Functional Specification Document

A especificação funcional completa está em [`DOCUMENTACAO-TECNICA.md`](./DOCUMENTACAO-TECNICA.md), na seção **FSD — especificação funcional**. Ela documenta autenticação, criação de quadros, carregamento/salvamento, importação/exportação, administração e contratos HTTP observados no código.
