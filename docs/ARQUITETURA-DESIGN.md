# Arquitetura e Design

A arquitetura detalhada, os diagramas Mermaid, o modelo relacional, as camadas, os fluxos de persistência, a autenticação, o cache, a observabilidade e o tratamento de erros estão em [`DOCUMENTACAO-TECNICA.md`](./DOCUMENTACAO-TECNICA.md), na seção **Arquitetura e design**.

O sistema combina páginas PHP, módulos JavaScript ES, endpoints PHP JSON, PDO, MySQL/MariaDB, arquivos JSON legados e PHPMailer. A documentação principal destaca a inconsistência entre o modelo antigo baseado em arquivo e a persistência atual baseada em banco.
