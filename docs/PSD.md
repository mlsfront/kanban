# PSD — Product/Project Specification

Este arquivo é a entrada específica da especificação do produto. A versão completa está em [`DOCUMENTACAO-TECNICA.md`](./DOCUMENTACAO-TECNICA.md), nas seções **Resumo executivo** e **Visão geral do produto/projeto — PSD**.

O produto analisado é uma aplicação web PHP de gestão visual de tarefas em quadros Kanban, com autenticação, persistência MySQL/MariaDB, modo de demonstração local, templates JSON, relatórios simples e painel administrativo. O escopo, requisitos funcionais, requisitos não funcionais, lacunas e pontos “Assumir/Investigar” estão consolidados no documento principal.
